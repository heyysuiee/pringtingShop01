Pricing management

Set each product's base price and the extra charge for each size, material, color, finish, or add-on. Select a row to set prices.

Prices are not invented. A product stays on “Request a quote” until an administrator enters its base price. Options marked “Quote only” always send the order for a quotation. The administrator confirms every order's final amount.
